# Changelog

## 1.0.0 — 2026-10-22

First public release of Trailing Stops for Omarchy.

- Configurable Buy dip, Buy bounce and trailing Sell stop alerts for Google Finance symbols.
- Bar widget and panel for subscriptions, thresholds, resets and phone notification settings.
- Critical desktop alerts and optional phone delivery through ntfy.
- Optional opening briefings, daily roundups and dip/bounce analyses, with Markdown/HTML
  articles, review notes, linked indexes and phone summaries.
- Opening coverage of Asian and European markets and conditional effects on each
  subscribed share, with strict historical information cutoffs.
- Shared Market Savant v2.1.0 research adaptation for drafting, fact-checking and revision:
  expectations, market regime, independent counter-evidence, uncertainty and watchpoints.
- Public news/report research; X/Twitter research is disabled. Trade sizing is excluded.
- Persistent premarket recovery and saved-article delivery retries, with delayed reports
  clearly labelled and completed work suppressed on repeat checks.
- Daily comparisons with the matching session's saved opening briefing, including
  explicit limitations on retrospective reconstructions.
- Omarchy-native Tailscale instructions, same-tailnet phone checks and prompt customisation guidance.

Report features require separately installed and authenticated Claude Code and/or Codex,
Python Markdown, network access and provider plan/API usage. Phone access to private reports
also requires configured hosting, ntfy and a connected phone. See the README for setup.

Marketplace verification is separate from this release and applies only to a reviewed
commit once the marketplace approves it. No verified status is claimed by this release.
